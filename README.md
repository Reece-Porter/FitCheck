# Rack & Rail — Pool Table Rules & Maintenance

A small static website covering the rules of pool and how to keep a pool
table in good playing condition.

## Pages

| File | Contents |
| --- | --- |
| `index.html` | Home page with an overview and links to the guides. |
| `rules.html` | Standard 8-ball rules (racking, breaking, fouls, winning) plus a quick 9-ball summary. |
| `fixing.html` | Maintaining and repairing a table: levelling, cleaning, cushions, re-felting, and re-tipping cues. |
| `style.css` | Shared styling for all pages. |

## Viewing the site

No build step is required — open `index.html` in any web browser, or serve
the folder locally:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Notes

Rules follow common standard conventions for casual play. House rules vary,
so agree on any differences before you break.
